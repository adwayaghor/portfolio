Team project. Five retrievers share one interface: naive vector RAG; tree RAG over a page index of long documents; Microsoft's GraphRAG with community summaries; SQL + RAG, our own design that pairs text-to-SQL with retrieved context; and a temporal knowledge-graph RAG adapted from an open-source implementation. A router reads each query and sends it to the method that suits it. In the browser, a small keyword classifier stands in for the router so you can watch the routing live.
